# Agent Guidance

For any edits to the book HTML, read [docs/HTML_MARKUP_MANUAL.md](docs/HTML_MARKUP_MANUAL.md) first and follow the conventions there.

For work on the optional reader-facing modernisation layer, also read [docs/MODERNISATION_LAYER_PROPOSAL.md](docs/MODERNISATION_LAYER_PROPOSAL.md). The proposal is not an implemented markup convention until its proof of concept is approved.

Key rules:

- Preserve the existing site shell and navigation structure.
- Keep historical spelling and punctuation unless correcting an OCR error.
- Use semantic HTML5 footnotes with explicit anchors and backlinks.
- Prefer updating the existing `text/*.html` pages instead of creating new layouts.
